# egov-law-downloader

e-Gov 法令 API を使って法令を検索し、本文や添付ファイルを保存するための小さなブラウザ UI です。

## Files

- `web/index.html`
- `lawapi-v2.yaml`

## できること

- 法令名で検索
- 検索結果から複数法令を選択
- `XML / JSON / HTML / RTF / DOCX` を保存
- 公式HTML本文を印刷ビューで開いて `PDFとして保存`
- 添付ファイルを `様式・図表を保存（ZIP）` で一括保存
- ステータスとログを画面内で確認

## PDF の扱い

`law_file` は `file_type=pdf` を提供していません。
このリポジトリでは、法令本文PDFを 2 通りで扱います。

### 1. `PDFとして保存`

ブラウザ UI の `PDFとして保存` は次の流れです。

1. `law_file/html/...` で公式HTML本文を取得
2. 公式本文の見た目に近い印刷ビューを別タブで開く
3. ブラウザの印刷ダイアログから PDF 保存する

現時点では、ブラウザUIから扱う PDF は `PDFとして保存` のみです。
これは公式HTML本文を印刷ビューで開き、ブラウザの印刷機能で保存する方式です。

## 添付ファイルの扱い

`様式・図表を保存（ZIP）` は `attachment` API を使って添付ファイルを一括取得します。様式、付録、図表ファイルなどをまとめて保存したい場合に使います。

## 使い方

### ブラウザ UI

1. `web/index.html` をブラウザで開く
2. 法令名を入力して Enter キー、または「法令を検索」で検索する（候補の上限は「検索オプション」で変更できます）
3. 保存したい法令にチェックを入れ、選択件数を確認する
4. 「形式を選んで保存」で目的に合う保存形式を選ぶ（XML・JSON・RTF は「その他の形式」から選択できます）
5. 過去の時点を指定する場合は「過去の時点を指定」を開き、基準日を選ぶ
6. 件数が表示された保存ボタンを押す

## 補足

- ブラウザ UI から内部APIへ直接アクセスできない箇所では、CORS の影響を受けます

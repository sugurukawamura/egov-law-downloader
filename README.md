# egov-law-downloader

e-Gov 法令 API Version 2 を使って法令を検索し、本文や添付ファイルを保存するブラウザ UI です。HTML・CSS・JavaScript をまとめた単一の HTML ファイルで動作します。

## 起動方法

リポジトリを取得し、[web/index.html](web/index.html) をブラウザで開いてください。ビルドやパッケージのインストール、バックエンドの起動は不要です。

JavaScript が有効なブラウザと、e-Gov 法令 API に接続できるインターネット環境が必要です。検索・取得のリクエストはブラウザから `https://laws.e-gov.go.jp/api/2` に直接送信します。通信制限（CORS）などにより利用できない環境もあります。

## 使い方

1. 「法令名」に名前を入力し、Enter キーまたは「法令を検索」で検索します。
2. 保存したい法令にチェックを入れます。「全て選択」「全て解除」は表示中の候補が対象です。
3. 「形式を選んで保存」で保存形式を選びます。複数の形式を同時に選べます。初期状態では HTML が選択されています。
4. 基準日を指定する場合は「過去の時点を指定（任意）」を開き、日付を入力します。
5. 選択件数と保存形式を確認し、保存ボタンを押します。PDF 以外はブラウザのダウンロード一覧で保存結果を確認してください。

検索をやり直すと、保存対象の法令の選択は解除されます。検索に失敗した場合は前回の候補が残り、その旨が表示されます。

### 検索結果の見方

- 「検索オプション」の「表示する候補の上限」は初期値が 50 件です。候補が足りない場合は件数を増やして再検索します。
- API には法令名と `repeal_status=None` を指定して検索し、取得した候補を法令名との一致度などで並べ替えます。
- 表示上限とは別に取得件数にも上限があるため、検索でヒットした全件を表示・比較するとは限りません。
- 各候補には法令番号、日付、添付ファイルの件数・種類を表示します。添付情報は検索後に取得するため、最初は「添付: 確認中」と表示されます。

### 保存形式

| 画面の選択肢 | 保存内容・操作 |
| --- | --- |
| ブラウザで読む（HTML） | ブラウザで開ける本文ファイルを保存します。 |
| Wordで使う（DOCX） | Word などで扱う本文ファイルを保存します。 |
| PDFとして保存 | 法令ごとに別タブで印刷画面を開き、利用者が PDF として保存します。 |
| 様式・図表を保存（ZIP） | 法令ごとに添付ファイルをまとめた ZIP を保存します。 |
| XML / JSON / RTF | 「その他の形式（XML・JSON・RTF）」を開いて選択します。 |

本文ファイルは法令・形式ごとに保存します。複数法令の本文を一つのファイルや ZIP にまとめる機能はありません。

### PDF の保存

「PDFとして保存」は、API から取得した公式 HTML 本文に A4 用紙サイズ・余白などの印刷設定を追加し、ブラウザの印刷機能で PDF にする方式です。e-Gov が配布する公式 PDF を直接取得する機能ではありません。

1. 保存形式で「PDFとして保存」を選びます。PDF だけが必要な場合は、初期選択の HTML のチェックを外してください。
2. 保存ボタンを押すと、法令ごとに印刷用の別タブが開きます。
3. 各タブの印刷ダイアログで、印刷先として「PDFとして保存」などを選び、保存します。

ポップアップがブロックされる場合は、この画面でのポップアップを許可して再実行してください。画面の「印刷画面を開きました」という表示は PDF の保存完了を意味しません。各印刷画面で保存操作が必要です。

### 添付ファイルの保存

「様式・図表を保存（ZIP）」は、`law_data` で添付情報を確認し、`attachment` API が返す ZIP を法令ごとに保存します。様式、付録、図表などをまとめて取得したい場合に使います。

候補の「添付: なし」は添付ファイルが存在しないことを示します。「添付: 確認失敗」は添付情報を取得できなかった状態であり、添付なしとは区別してください。添付のない法令で ZIP を保存しようとするとエラーになります。

### 基準日の指定

基準日は `YYYY-MM-DD` 形式で扱い、本文・添付情報の取得時に API の `asof` パラメーターとして送信します。未入力の場合は `asof` を送信しません。

基準日を変更しても検索結果の法令一覧は変わりません。添付情報は指定した基準日で再取得します。過去の法令を検索し直す機能ではなく、実際に取得できる内容は API の応答に依存します。

### 保存ファイル名

- 本文: `法令名_YYYYMMDD.html` など、選択した形式の拡張子を付けます。
- 添付 ZIP: `法令名_YYYYMMDD_添付ファイル_PDF1_PNG2.zip` など、添付の種類・件数を付けます。
- PDF: 印刷画面のタイトルに `法令名_YYYYMMDD.pdf` を設定します。実際の保存名は印刷ダイアログで確認してください。

ファイル名の日付は検索結果の改正施行日などから決まり、入力した基準日とは限りません。利用できる日付がない場合は端末の当日の日付を使います。ファイル名に使えない一部の記号は `_` に置換します。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 検索・保存に失敗する | 「処理の詳細・ログ」を開き、エラー内容や HTTP ステータスを確認します。通信環境を確認して再試行してください。CORS によって利用できない環境もあります。 |
| 保存ボタンを押せない | 法令を 1 件以上、保存形式を 1 つ以上選択してください。検索・保存の処理中は完了を待ちます。 |
| PDF の別タブが開かない | ブラウザのポップアップ許可を確認してください。複数法令を選ぶと複数のタブが開きます。 |
| 複数ファイルが保存されない | ブラウザのダウンロード一覧と、複数ファイルの自動ダウンロードに関する許可を確認してください。 |
| 基準日のエラーが出る | 実在する日付を入力するか、基準日を空欄に戻してください。 |
| 途中で保存が止まる | 取得エラーが起きると、その時点で残りの処理を中断します。ログとダウンロード一覧で保存済みのファイルを確認し、必要な法令・形式を選び直して再実行してください。 |

ローカルで取得した API 仕様書 `lawapi-v2.yaml` と検証用の `tests/` は `.gitignore` の対象で、リポジトリの配布ファイルには含まれません。

主な API 呼び出しは次のとおりです。パスは `https://laws.e-gov.go.jp/api/2` からの相対パスです。

| 用途 | メソッド・パス | 主な指定 |
| --- | --- | --- |
| 法令検索 | `GET /laws` | `law_title`、`repeal_status=None`、`response_format=json`、`limit`、`offset` |
| 本文ファイル | `GET /law_file/{形式}/{法令識別子}` | 基準日を入力した場合は `asof`。PDF 用にも HTML を取得。 |
| 添付情報 | `GET /law_data/{法令識別子}` | `response_format=json`、基準日を入力した場合は `asof`。 |
| 添付 ZIP | `GET /attachment/{law_revision_id}` | 添付の個別パスを指定せず一括取得。 |

画面・処理を変更した場合は、ブラウザで次を確認してください。リポジトリに自動テストやビルド用の設定は含まれていません。

1. 法令名を Enter キーと検索ボタンで検索でき、候補の表示上限を変更できること。
2. 個別選択・全て選択・全て解除に応じて、選択件数と保存ボタンが更新されること。
3. 本文ファイルを保存でき、複数法令・複数形式ではそれぞれのダウンロードが始まること。
4. PDF の別タブで印刷画面が開き、PDF として保存できること。
5. 添付のある法令で ZIP を取得でき、添付のない法令ではエラーが表示されること。
6. 基準日の入力・クリアで添付情報が再取得されること。検索・保存の失敗時には画面とログで確認できること。
